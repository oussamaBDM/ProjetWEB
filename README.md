# CAPCOM – Mobilité écologique en entreprise

## Présentation du projet

Ce projet a été réalisé dans le cadre d'un travail de groupe de **3 étudiants**. L'objectif était de concevoir un site web présentant une entreprise de notre choix et mettant en avant ses initiatives en faveur de l'environnement.

Nous avons choisi **CAPCOM** comme entreprise support de notre présentation. Le site met particulièrement en lumière les solutions de mobilité écologique proposées aux collaborateurs pour leurs déplacements quotidiens.

Deux dispositifs sont présentés :

- **La location de vélos** : une alternative écologique à la voiture individuelle pour les trajets domicile-travail.
- **Le covoiturage** : une solution permettant de partager les déplacements, de réduire le nombre de véhicules sur la route et de limiter les émissions de CO₂.

## Objectifs du projet

- Concevoir un site web de présentation d'entreprise.
- Mettre en valeur des initiatives en faveur de la mobilité durable.
- Organiser les informations de manière claire et accessible.
- Proposer une navigation entre une page de connexion et un espace d'accueil complet.

## Fonctionnalités

- Page d'entrée permettant d'accéder à l'espace de connexion.
- Interface de connexion.
- Page d'accueil principale présentant le contenu du site.
- Présentation des solutions de mobilité écologique : location de vélos et covoiturage.

## Lancer le projet

Le site est un projet web à exécuter localement.

Pour y accéder, il faut ouvrir en premier le fichier :

`index_connexion.html`

Ce fichier constitue le point d'entrée du site et permet d'accéder à la page de connexion, puis à la page d'accueil complète.

## Travail en équipe

Le projet a été réalisé en groupe de trois étudiants. Nous avons travaillé ensemble sur la conception et la réalisation du site, ainsi que sur l'organisation et la présentation des informations relatives aux engagements environnementaux de l'entreprise.
